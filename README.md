# Эмулятор командной оболочки ОС (Вариант 18)

## Описание
Поэтапная разработка эмулятора командной оболочки UNIX-подобной ОС.

## Запуск
```bash
./run.sh [--vfs ПУТЬ] [--script ПУТЬ]
```

- `--vfs` — путь к физическому расположению VFS.
- `--script` — путь к стартовому скрипту.

## Этап 2. Конфигурация
- Параметры командной строки: `--vfs`, `--script`.
- Отладочный вывод всех параметров при запуске.
- Стартовый скрипт выполняется построчно, **ошибочные
  строки пропускаются**, в конце выводится количество ошибок.
- Диалог имитируется: на экран выводятся и ввод, и результат.
- Скрипты реальной ОС для тестирования лежат в `scripts/`.

## Тестирование
```bash
bash scripts/test_emulator.sh
```
