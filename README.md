# Эмулятор командной оболочки ОС (Этап 1)

## Общее описание
Минимальный прототип эмулятора командной оболочки UNIX-подобной ОС.
Реализован в виде консольного интерфейса (CLI) на языке Python.
На данном этапе поддерживается интерактивный диалог с пользователем (REPL),
команды `ls` и `cd` являются заглушками, а команда `exit` завершает работу.

## Функции и настройки
- **Приглашение к вводу**: содержит имя VFS (по умолчанию `vfs`).
- **Парсер команд**: корректно обрабатывает аргументы в кавычках (одинарных и двойных).
- **Команды**:
  - `exit` — завершение работы эмулятора.
  - `ls [аргументы]` — заглушка, выводит своё имя и переданные аргументы.
  - `cd [аргументы]` — заглушка, выводит своё имя и переданные аргументы.
- **Обработка ошибок**: при вводе неизвестной команды выводится сообщение об ошибке.
